The vacuum cleaner's alibi, in one line: where was it when the mess happened, who can vouch for it, and what does it say about the crumbs?

> I was unplugged in the closet all evening — the dust bunnies saw me. Those crumbs on the carpet? Never met them, officer.

## Run it

```sh
python3 main.py
```

This writes the alibi to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
